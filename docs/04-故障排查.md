# 04 · 故障排查

> 按现象查表。先跑一遍自检：`python enigma-launch\selfcheck.py`。

---

## 1. 双击没反应 / 窗口一闪而过

**原因**：Python 不在 PATH，或 `.bat` 的退出码 < 4（正常结束）。

**处理**：

1. 打开命令行，运行：
   ```bat
   python --version
   ```
   没有输出 → 安装 Python 3.8+，安装时勾选 **Add Python to PATH**。
2. 也可以直接用命令行运行，方便看报错：
   ```bat
   python enigma-launch\enigma_launch.py
   ```

---

## 2. 提示「找不到游戏主程序」

```
找不到游戏主程序。
可以这样指定：
  python enigma_launch.py --exe "D:\Games\enigma\你的文件名.exe"
  ...
```

**原因**：目录结构不对、主程序被改名/移动，或启动器被单独复制到了别处。

**处理**（任选一种）：
- 用 `--exe` 指定主程序（支持任意文件名）：
  ```bat
  python enigma-launch\enigma_launch.py --exe "D:\Games\enigma\我的游戏.exe"
  ```
- 直接把目录或文件作为参数：
  ```bat
  python enigma-launch\enigma_launch.py "D:\Games\enigma"
  ```
- 写一个 `launcher.json`（见 [06-自定义路径与名称.md](06-自定义路径与名称.md)）；
- 把启动器放回游戏根目录（或子目录），让它自动向上查找。

先看解析结果：

```bat
python enigma-launch\enigma_launch.py --check
```

---

## 3. 等不到注册对话框（返回码 4）

**原因**：上一次的游戏/壳进程还活着，或壳被安全软件拦截。

**处理**：

```bat
taskkill /F /IM crackme.exe
```

再重跑。若仍不行：
- 检查是否已有 `目标程序窗口` 窗口（游戏已在运行）；
- 检查杀毒软件是否隔离了 `crackme.exe`。

---

## 4. 点「注册」后弹出「注册没成功」

**原因**：补丁没打上（地址不对 / 时机不对），或描述符值被别的东西覆盖。

**处理**：
1. 看控制台日志里 `映像基址` 和 `描述符标记`：
   - 基址应为 `0x453000`；
   - 标记应为 `0x2C/0x2D`（打印「与预期不同」说明版本不同）。
2. 确认等待了 1.2 秒（日志里 `已打补丁` 的时间应 ≥ 1.2s）；
3. 关闭游戏、杀进程、重跑。

---

## 5. 成功注册后没有游戏窗口（返回码 7）

**原因**：壳在启动原程序时失败（数据文件缺失 / 被拦截）。

**处理**：
- 确认 `test\data`、`test\graphic` 等目录完整（缺失时 `run_all.py` 会从 `bk\` 补齐）；
- 检查杀软是否拦截了壳的解密/执行；
- 重跑一次；仍失败可换用根目录的 `启动游戏.bat`（等价）。

---

## 6. 游戏窗口出现又立刻消失

**原因**：通常是重复启动（已有实例）或显卡/兼容性。

**处理**：
- 先关掉所有 `crackme.exe` 再重跑；
- 确认 `test\config.txt` 没被改坏（窗口尺寸等）；
- 以窗口模式运行（默认已是窗口模式）。

---

## 7. 提示「游戏已经在运行」

```
游戏（或它的注册对话框）已经在运行，无需重复启动。
```

**说明**：启动器检测到 `hspwnd0` 或注册对话框窗口。
直接切到游戏窗口即可；若要重启，先关闭游戏。

---

## 8. 杀毒软件报警

**说明**：启动器本身只做 `OpenProcess` + `WriteProcessMemory`，
但这类行为与游戏外挂/注入工具相似，可能被启发式规则误报。

**处理**：
- 将本目录加入信任；
- 不需要联网、不写注册表、不修改游戏文件（`license.s2` 是壳写的）。

---

## 9. 每次都要运行启动器，正常吗？

**正常**。原因见 [01-原理 §7](01-原理.md)：
壳下次启动会重新用公钥校验 `license.s2`，假注册码必然失败。

---

## 10. 启动器放在 `enigma-launcher\` 里还能用吗？

**可以**。`enigma_launch.py` 只会在项目内查找
`test\crackme.exe` / `bk\crackme.exe`（不访问项目外）。

---

## 11. 想确认到底发生了什么

打开命令行运行：

```bat
python enigma-launch\enigma_launch.py
```

正常输出示例：

```
[  0.01s] 启动 crackme.exe
[  0.24s] 注册对话框已出现
[  1.44s] 映像基址 0x453000，描述符标记 0x2d / 0x2c
[  1.44s] 已打补丁: 描述符 0x7615a8 / 0x75af1c = 0x03
[  1.75s] 已点击「注册」
[  2.19s] 已点击「成功注册」提示框的 OK
[  3.79s] 游戏已启动：'目标程序窗口' (窗口 0x2c0792)
```

若在 `已打补丁` 之前就退出，看返回码（见 02-技术细节 §7）。
