# 06 · 自定义执行文件路径与名称

> 启动器默认使用项目内的 `test\crackme.exe`（原始备份在 `bk\`）：
> 主程序也可以**改名、换目录、换盘符**，只要能让启动器找到它即可。
> 重建流水线（`run_all.py`）则只接受项目 `bk\` 里的原始程序。

---

## 1. 三种指定方式

### 方式 A：位置参数（最顺手）

```bat
:: 给目录：自动在目录里找 crackme.exe / unenigma.exe / 唯一的 exe
python enigma_launch.py "D:\Games\enigma"

:: 给文件：任意文件名
python enigma_launch.py "D:\Games\enigma\我的游戏.exe"
```

双击 `启动游戏.bat` 时也可以：

```bat
启动游戏.bat "D:\Games\enigma\我的游戏.exe"
```

> 启动器会判断第一个参数是不是**已存在的文件或目录**；
> 是的话当作路径，否则当作玩家名。

### 方式 B：显式参数

```bat
python enigma_launch.py --exe "D:\Games\enigma\我的游戏.exe"
python enigma_launch.py -e "D:\Games\enigma\我的游戏.exe" --wait 1.5
python enigma_launch.py --game-dir "D:\Games\enigma"
python enigma_launch.py -g "D:\Games\enigma" -w 1.8
```

| 参数 | 作用 |
|---|---|
| `-e, --exe PATH` | 主程序文件，或包含主程序的目录 |
| `-g, --game-dir DIR` | 游戏目录（自动查找已知 exe 名 / 唯一 exe） |
| `-c, --config FILE` | 指定配置文件 |
| `-w, --wait SEC` | 对话框出现后的等待秒数（默认 1.2） |
| `--check` | 只解析并打印结果，不启动 |

### 方式 C：配置文件（一次设置，以后双击）

把 `launcher.example.json` 复制为 `launcher.json`：

```json
{
  "exe": "D:/Games/enigma/我的游戏.exe",
  "player": "enigma",
  "wait": 1.2
}
```

或只给目录：

```json
{
  "game_dir": "D:/Games/enigma",
  "player": "enigma"
}
```

| 字段 | 说明 |
|---|---|
| `exe` | 主程序路径（文件或目录） |
| `game_dir` | 游戏目录（与 `exe` 二选一） |
| `player` | 默认玩家名 |
| `wait` | 等待秒数 |

**相对路径**：`exe` / `game_dir` 中的相对路径**相对配置文件所在目录**解析。
例如配置文件在项目根目录，写
`"exe": "test/crackme.exe"` 就会解析到项目内的 `test\crackme.exe`。

---

## 2. 解析优先级

```
--exe / 位置参数（文件或目录）
        ↓ 没有
--game-dir / 位置参数（目录）
        ↓ 没有
--config 指定的配置（或默认 launcher.json）
        ↓ 没有
自动探测（只在项目内）：
  项目根目录
  依次检查 test\、bk\、根目录本身
  找 crackme.exe / unenigma.exe / 目录中唯一的 exe
```

先命中者生效。

---

## 3. 目录模式怎么选 exe

给的是**目录**时，按顺序：

1. 目录里有 `crackme.exe` → 用它；
2. 否则有 `unenigma.exe` → 用它；
3. 否则目录里**只有一个** `.exe` → 用它；
4. 否则失败，提示用 `--exe` 指定具体文件。

所以「把 `crackme.exe` 改名成 `enigma.exe` 并单独放在一个目录里」也能直接用
目录模式启动。

---

## 4. 工作目录（很重要）

启动器把**主程序所在目录**设为工作目录：

```python
subprocess.Popen([exe], cwd=os.path.dirname(exe))
```

原因：壳/游戏会从工作目录找 `data\`、`graphic\` 等数据。
所以移动游戏时，**整个 `test\` 目录要一起移动**（exe + data + 各子目录），
不能只搬 exe。

---

## 5. 改名后还能用吗

可以。启动器与壳的交互只依赖：

- 进程 PID（`OpenProcess`）；
- 窗口类名（`TEnigmaProtectorLoader*`、`hspwnd0`）；
- 内存里的两个描述符偏移。

这些都与**文件名**无关。改名后：

- 注册对话框、补丁、启动流程完全一样；
- 只要 `data\` 等目录跟着 exe 走，游戏数据正常。

---

## 6. 检查解析结果

```bat
python enigma_launch.py --check
python enigma_launch.py --exe "D:\Games\enigma\我的游戏.exe" --check
```

输出示例：

```
解析结果：
  主程序 : D:\Games\enigma\我的游戏.exe
  工作目录: D:\Games\enigma
  玩家名 : enigma
  等待   : 1.2 秒
```

`selfcheck.py` 也支持同样的参数：

```bat
python selfcheck.py --exe "D:\Games\enigma\我的游戏.exe"
```

---

## 7. 常见错误

| 提示 | 原因 | 处理 |
|---|---|---|
| `找不到游戏主程序` | 路径不对 / 目录里 exe 不唯一 | 用 `--exe` 指定具体文件 |
| `读取配置失败` | JSON 语法错误 / 文件不存在 | 用 `--check` 看报错；检查逗号、引号 |
| `Config file ... not found` | `--config` 路径写错 | 用绝对路径 |
| 游戏窗口不出现 | 只搬了 exe，没搬数据目录 | 整个 `test\` 一起移动 |
| `已经在运行` | 旧进程没关 | `taskkill /F /IM 你的文件名.exe` |
