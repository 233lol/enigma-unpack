# 总览：从 crackme 到可运行

> 目录约定：`bk\` 是原始程序备份（crackme.exe + 游戏资源，不修改）；
> `test\` 是运行/测试副本（可从 bk 恢复）；`tmp\` 放所有临时文件；
> `out\` 放最终产物。流水线不读取、不写入项目文件夹以外的路径。

本项目把两件事合到一起，放在同一个文件夹里，只依赖一份加壳的 `crackme.exe`
和完整游戏资源目录：

1. **启动（运行时绕过注册）**：`enigma_launch.py` / `一键启动游戏.bat`
2. **脱壳重建（静态还原 + 运行时数据恢复）**：`run_all.py` / `extract\` + `build\`

## 二、为什么只有「一个函数」需要重建

对原程序映像（运行时映射在 `0x400000`）做同步反汇编，指向壳映像
（`0x453000..0xC32000`）的直接 `call/jmp` 只有一处：

```
0x41AFF0: e8 8f fb 18 00    call 0x5AAB84    ; WinMain -> 壳的 VM 跳板
```

也就是说 **Enigma 只虚拟化了 `WinMain`**，其余机器码原样。于是：

- 从运行进程在 OEP 抓原程序映像（`extract_oep.py`）；
- 用 HSP3 源码语义在 `0x41AFF0` 写回原生 WinMain（`restore_winmain.py`）；
- 重建 PE 与导入表、补入口桩/TLS（`build_exe.py` / `add_entry.py` / `add_tls.py`）。

关键地址（VA，基址 `0x400000`）：

| 名称 | 地址 | 说明 |
|---|---|---|
| WinMain | `0x41AFF0` | 唯一被虚拟化，需重建 |
| hsp3win_init / exec | `0x414C70` / `0x414A70` | WinMain 调用的两个函数 |
| 真实 CRT 入口 | `0x4209E9` | 会调用 WinMain |
| OEP（抓取点） | `0x4209E9` / `0x420F3C` | 分别在入口 / security cookie 处 |
| Hsp3::Reset | `0x401CF0` | 加载并 XOR 解密脚本 |
| 脚本 XOR pad | 71 字节固定表 | `stored[i] = plain[i] ^ pad[i % 0x47]` |
| HSPHED 模板 | `0x44C08C` | `.data` 里的 pack 字段 |
| `_tls_index` | `0x44DFB8` | 静态 TLS |
| CRT 初始化标记 | `0x44DF6C` / `0x44DF75` | OEP 时应为 0 |

## 三、提取的两个关键机制

### 1. OEP 映像（`extract_oep.py`）

不能挂调试器（会被检测）。做法是给**每个线程**设硬件执行断点 `DR0 = OEP`，
进程未被调试器附加时，命中会产生未处理异常 → **Windows 错误报告**写出全量转储。
再从转储的内存列表里拼出 `0x400000..0x453000`。

单次命中不一定落在「已解密、CRT 未运行」那一刻，所以脚本会**校验 + 重试**：

```
MZ 头 && .data 里 0x44C08C == "HSPHED~~" && 代码段非空
      && [0x44DF6C]==0 && [0x44DF75]==0
```

实测 `DR0=0x4209E9` 一次命中即可通过。

需要先配置 WER LocalDumps（`启用错误转储.bat`，管理员一次）。

### 2. 脚本主体 start.ax（`extract_script.py`）

启动游戏后，`Hsp3::Reset` 已把 `start.ax` 读进一块堆内存并解密。扫描可读内存里
以 `HSP3` 开头、长度写在头部 +12 的对象，按字段合理性挑出真正的脚本整块导出。

## 四、脚本库 DPM 与 XOR

- DPM 格式：`DPMX` + `optr/dent/namsize` + 条目表（每 32 字节）+ 数据区。
- `Hsp3::Reset` 只对它加载的那一个文件（`start.ax`）做固定 pad 的 XOR 解密，
  所以存进 DPM 的 `start.ax` 必须**预 XOR**；`scene*.hsp` 明文存放。
- 单文件版：把 DPM 追加到 exe 末尾，改写 `.data` 的 `optmes`（pack 字段），
  HSP 就会从自身映像里加载（见 `build_singlefile.py`）。
