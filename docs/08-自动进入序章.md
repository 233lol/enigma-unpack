# 08 · 自动进入序章（复现 HspError 12）

用户提供的、可以真正进入序章的角色创建按键顺序：

```text
b,b,b,b,b,b,b,b,b,a,b,a,b,enter,a,Esc,a,输入角色名称,enter
```

注意：

- 每个按键之间要留足时间（游戏加载/画面切换有延迟，建议 0.8–1.2 秒）。
- 窗口必须保持焦点；工具会在每次按键前 `SetForegroundWindow` 并点击一次游戏窗口。
- 角色名输入后按 `enter`，下一步就是序章。修复前重建版会在这里触发
  `HspError 12 WinError 2 ... invalid chara position`；根因与修复见下方
  「结论」一节。

## 已保存的工具

| 文件 | 用途 |
|---|---|
| `tools\auto_seq.py` | 用上面的按键顺序自动创建角色，可指定游戏目录 / exe / 按键间隔 |
| `tools\auto_orig.py` | 先跑启动器绕过注册，再对原版 `crackme.exe` 执行同一套按键 |
| `tools\auto_char.py` | 早期逐屏选择角色的实验脚本（保留作参考） |

用法（在项目根目录执行）：

```bat
:: 重建版（会在这里复现崩溃）
python tools\auto_seq.py test unenigma_single.exe 1.0

:: 原版（应能进入序章）
python tools\auto_orig.py test crackme.exe 1.0
```

设置环境变量 `KEEP=1` 可以在脚本结束后保留游戏进程，方便截图：

```bat
set KEEP=1
python tools\auto_seq.py test unenigma_single.exe 1.0
```

## 结论（已定位并修复）

真正的崩溃原因不是角色数组，也不是存档目录：

1. `HspError 12` 是 HSP 的 **FILE_IO**，`WinError 2` 是 **文件不存在**。
2. 游戏在 `Scene:Init` 里打开的是绝对路径
   `GetTempPathA()\scene1.hsp`（本机为 `<项目>\tmp\scene1.hsp`）。
3. 原版的这两个文件由 **Enigma 虚拟文件系统**在运行时提供，磁盘上没有；
   脱壳版没有 VFS，打开失败 → `HspError 12` → 写 `error.txt`
   （后面的 `* invalid chara position ...` 只是游戏残留的诊断文本，不是根因）。
4. 实测：手动把 `scene1.hsp` / `scene2.hsp` 放进 `%TEMP%` 后，重建版新建角色
   可以正常进入序章，无报错。

修复方式（`build\add_scene_boot.py`）：

- 把校验过的 `scene1.hsp` / `scene2.hsp` 放进重建 exe 新增的 `.scn` 段；
- 把 `AddressOfEntryPoint` 指向一个小启动桩：先用 `GetTempPathA` +
  `MultiByteToWideChar` + `CreateFileW` + `WriteFile` 写出
  `%TEMP%\scene1.hsp` / `scene2.hsp`，再跳回原入口（`0x4209E9` 前的入口桩）。
- 因此 `unenigma.exe` / `unenigma_single.exe` 双击即可，不再需要手工准备临时文件。

## 历史记录：加载原版存档的临时办法

在修复前，原版 `crackme.exe` 创建的存档 `test\save\sav_test1` 可以被重建版直接
加载并正常进入游戏世界。现在这条办法仍然可用，但已不再是必需的。

## 补充：用户后来给的简写

```text
bbbbbabab
aatest
```

这组简写不是完整流程；完整且可用的顺序是：

```text
b,b,b,b,b,b,b,b,b,a,b,a,b,enter,a,Esc,a,输入角色名称,enter
```

之前自动化停在「才能选择」画面，是 **窗口焦点没有对上**，不是按键顺序错。
修正焦点后，重建版确实进入了序章，并在序章 `Scene:Init` 崩溃。
根因与修复见上一节；现在同一套按键可以正常进入序章。

## 已验证可行的办法：用原版存档启动重建版

原版 `crackme.exe` 创建的存档 `test\save\sav_test1` 可以被重建版直接加载，
并且能正常进入游戏世界（地图、角色、状态栏都正常）。

也就是说：

- **新建角色 → 序章**：修复后不再崩溃。
- **加载原版存档**：重建版同样正常。

如需旧办法：

1. 用 `一键启动游戏.bat`（原版）创建一个角色并保存；
2. 用 `test\unenigma_single.exe` 启动重建版，选「再开冒险之旅」加载存档。
